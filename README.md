# 💳 Bank Transfer Management System

A **Java Console-Based Bank Transfer Management System** developed using **Java** and **IntelliJ IDEA**. This project simulates real-world banking operations such as account creation, deposits, withdrawals, balance inquiry, and secure money transfers between accounts.

---

## 📖 Project Overview

The **Bank Transfer Management System** is designed to demonstrate core Java programming concepts by implementing a simple banking application. It provides users with the ability to manage accounts and perform banking transactions while following Object-Oriented Programming (OOP) principles.

---

## ✨ Features

- 🏦 Create New Bank Accounts
- 💰 Deposit Money
- 💸 Withdraw Money
- 💳 Check Account Balance
- 🔄 Transfer Money Between Accounts
- 🆔 Generate Unique UTR ID for Every Transaction
- 📜 Maintain Transaction History
- ✅ Account Validation
- ⚠️ Custom Exception Handling

## 🚀 Functionalities

### ✅ Create Account
- Create multiple bank accounts.
- Store account details.

### 💰 Deposit Money
- Deposit money into an existing account.
- Automatically update the account balance.

### 💸 Withdraw Money
- Withdraw money from an account.
- Prevent withdrawal if the balance is insufficient.

### 💳 Balance Inquiry
- Display the current account balance.

### 🔄 Money Transfer
- Transfer money securely from one account to another.
- Validate both sender and receiver accounts.
- Generate a unique UTR ID for every successful transfer.

### 📜 Transaction History
- Store every successful transaction.
- Display complete transaction history.
